## Modules

| Module | Syllabus | Status |
|---|---|---|
| Module 1 | Image fundamentals – picture as a collection of pixels; binary, grayscale and colour images; colour models; space requirements. Applications of image processing. Image sampling and quantization. Neighbours of a pixel, adjacency, connectivity, boundaries, distance measures, pixel-wise image operations. Spatial domain operations – image negatives, log transformations, histogram. Fundamental steps in digital image processing. Components of an image processing system. | Pending |
| Module 2 | Image enhancement – histogram equalization, histogram matching, image subtraction, averaging, spatial filters, smoothing and sharpening filters. Enhancement in the frequency domain – 2-D DFT, frequency domain filters. Basic concepts of the discrete wavelet transform. Advantages of frequency domain operations. Generating a spatial mask from the frequency domain. | Pending |
| Module 3 | Pseudo-colour image processing – intensity slicing, gray level to colour, colour complements, colour slicing, halftoning, colour segmentation, noise in colour images. Image compression – coding, interpixel and psychovisual redundancy; lossy and lossless. Lossless predictive coding. Lossy compression – lossy predictive coding, transform coding. Image compression standards, the JPEG procedure, concepts of image security. | Pending |
